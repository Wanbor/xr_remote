Simple graphics remote controller (similar to XAir-Edit) for digital mixers Behringer XR16 and XR18

Instalation and run:

pip install python-osc

python xr16_18_remote.py

- double-left-click on channel name on top (CH01-CH18) open new window with other parameteres to change

- double-left-click on channel number on bottom change channel name

- right-click on channel number on bottom change color

Thats all ! ;-)
